Examples:
  yaya frame get 0x0 -t 0x12 --registers 0:int,2:object
  yaya frame set 0x0 -t 0x12 0 --type int --value 85

Outside interactive mode, select a session using command options or YAYA_SESSION. Copy frame and thread IDs from thread stack. JDWP requires a suspended thread. Get fresh frame IDs after resuming or stepping. Use decimal JDWP slot numbers without prefixes (0..2147483647). Android 16 tests confirmed direct correspondence with DEX register numbers; other ART versions may require a different mapping. These are VM variable slots, not CPU registers.
Use frame this to query the receiver directly with StackFrame.ThisObject.
