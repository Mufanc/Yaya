Examples:
  yaya class prepare watch 'com.example.*'
  yaya class prepare watch '*' --suspend none --count 1

Watch registers one EventRequest.Set and returns event_request_id immediately; it does not wait or stream events. Receive events with events, events -w or events -c. --suspend none|thread|all defaults to thread. --thread/-t limits the triggering thread. --count N must be 1..2147483647 and reports only the Nth matching event once, not N events; Count follows all other filters. No local request registry, automatic retry, capability probe or implicit resume. VM errors are returned directly. Outside interactive mode, select a session using command options or YAYA_SESSION. PATTERN is a dot-separated class name, an exact match or a single leading/trailing '*'; quote it in a shell. It is not a JNI signature, substring search or general regex. No class resolution occurs, so the class need not be loaded. Reports future class preparation only; no replay or delayed breakpoint registration. Output contains thread, type_tag, type_id, signature and status. A debugger-system-thread preparation may report thread 0 and promote event-thread suspension to all; trust the batch suspend_policy.
