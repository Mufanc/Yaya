Examples:
  yaya field access watch 'Lcom/example/Card;' height --suspend thread
  yaya field modification watch 'Lcom/example/Card;' height --suspend none --count 1

Watch registers one EventRequest.Set and returns event_request_id immediately; it does not wait or stream events. Receive events with events, events -w or events -c. --suspend none|thread|all defaults to thread. --thread/-t limits the triggering thread. --count N must be 1..2147483647 and reports only the Nth matching event once, not N events; Count follows all other filters. No local request registry, automatic retry, capability probe or implicit resume. VM errors are returned directly. Outside interactive mode, select a session using command options or YAYA_SESSION. Supply the declaring class's loaded JNI signature and declared field name. --type-id resolves class-loader ambiguity. Inherited fields require their declaring class; duplicate declared names fail rather than selecting arbitrarily. Resolves type and field IDs, then sends FieldOnly; does not read the field value. The event kind comes from access or modification. Target support is required, with no fallback. Events include thread, location, type_tag, type_id, field_id and tagged object (null for static fields); modification also includes typed value_to_be.
