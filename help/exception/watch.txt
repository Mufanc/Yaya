Examples:
  yaya exception watch --all
  yaya exception watch 'Ljava/lang/NullPointerException;' --with-caught
  yaya exception watch --all --caught-only --suspend none -t 0x12 --count 1

Watch registers one EventRequest.Set and returns event_request_id immediately; it does not wait or stream events. Receive events with events, events -w or events -c. --suspend none|thread|all defaults to thread. --thread/-t limits the triggering thread. --count N must be 1..2147483647 and reports only the Nth matching event once, not N events; Count follows all other filters. No local request registry, automatic retry, capability probe or implicit resume. VM errors are returned directly. Outside interactive mode, select a session using command options or YAYA_SESSION. Choose exactly one loaded JNI exception signature or --all; --all means every exception type, not both catch modes. A selected type includes its subtypes. Use --type-id with a signature to resolve class-loader ambiguity; missing classes fail immediately. Default: caught=false, uncaught=true. --with-caught sets both true; --caught-only sets caught=true, uncaught=false; these flags conflict. Events occur when thrown, not when the exception object is allocated. For native throws, the location is the first non-native location reached; native handlers can limit caught/uncaught prediction. Output contains thread, throw location, tagged exception and catch_location (null if uncaught).
